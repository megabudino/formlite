## Codebase Patterns
- Database path is read from env.DATABASE_PATH with fallback ./data/freeform.db.
- better-auth uses emailAndPassword.disableSignUp to block email/password signup while keeping sign-in enabled.
- Auth pages reuse local .auth-container and .auth-card styles for layout.
- better-auth credential passwords are stored as `saltHex:hashHex` using scrypt (N=16384, r=16, p=1, dkLen=64).
- Form settings use similar UI patterns for lists (emails, webhooks) with add/remove actions.
- Migrations are registered in `src/lib/migrations/index.ts` and applied via `runMigrations` in `src/lib/db.ts`.
